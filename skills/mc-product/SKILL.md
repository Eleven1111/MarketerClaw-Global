## 模块 2：产品差异化与「品类量化立规」

> 实体消费品需避开 Amazon Camera Search / Google Lens 同款比价时，加载 `references/physical-craft-premium.md` §1「形·色·纹·图」四维轻改造矩阵与 §2 知识产权边界。

### 2.1 品类量化立规（把模糊形容词翻译成可检测公差标尺）

成熟跨境品类中，写 `"Heavy Duty / Ultra Quiet / Premium Quality"` 只会被买家忽略甚至触发合规质疑。破局核心是**品类量化立规**——将行业模糊形容词改写为买家直观可读、第三方实验室可复现的公差标准：

| 禁用空洞形容词 | 品类量化立规方向 | 交付给工厂与 Listing 的硬标尺示例 | 买家可核验方式 |
|--------------|----------------|--------------------------------|--------------|
| Heavy Duty / Thick | 克重、壁厚公差、牌号与负载倍数 | 316L 不锈钢内胆壁厚 `≥ 0.8mm`；静态承重实测 `≥ 300 lbs`（公差 ±3%） | 游标卡尺微距实拍、真实负载测试视频 |
| Ultra Quiet / Smooth | 分贝实测距离、表面粗糙度、粒径 | 1 米距离实测运行噪音 `< 38 dB`；表面粗糙度 `Ra ≤ 0.2 μm` | 分贝仪同框测试条件、9x 微距对比图 |
| Durable / Long-lasting | 疲劳循环次数、色牢度与防泼水等级 | 50 次标准机洗回弹率 `≥ 95%`；真实认证 `IPX5` 防泼水测试 | 第三方检测报告编号、测试条件注释 |
| Hassle-Free Support | 明确响应时效与质保边界 | 工作日 `≤ 12 小时` 工单响应；真实注册期质保服务 | 官方客服 SLA 说明（禁止绑好评条件） |

**合规红线**：量化标尺必须具备真实出厂检验或第三方实验室依据，**禁止**虚标材质参数、禁止量产批次暗自降配掺水（adulteration）或以次充好，且所有度量衡按目标市场同步标注（US 用英寸/磅/华氏度并附公制括号）。

## 模块 4：开箱体验与「三态买家传播动机」设计

包装是海外买家拆开快递后的第一物理触点，但 **Amazon FBA 与 Shopify 独立站的合规边界截然不同**：

| 维度 | Amazon FBA 渠道（严格受限） | Shopify DTC / 独立站（自有品牌阵地） |
|-----|---------------------------|-----------------------------------|
| **外箱与内衬** | 扛住暴力分拣防破损、控制材积重在目标 Size Tier 内、清晰原产地（`Made in China`）与窒息警告 | 强化开箱仪式感与美学视觉锤（详见 `physical-craft-premium.md` §3） |
| **随包插卡 (Insert)** | **仅限**使用指南、安全提醒、中性售后支持入口；**严禁**好评返现、评价筛选门控或引导离站独立站下单 | 可附品牌档案卡、配件/耗材复购指南、社媒开箱标签引导（带激励须按 FTC 披露） |

### 三态买家自传播动机拆解（决定产品自带多少自然 UGC）

| 受众状态 | 核心心理诉求 | 产品/开箱内嵌载体 | 海外合规红线 |
|---------|------------|-----------------|------------|
| **1. 围观受众（未购破圈层）** | 猎奇、实用避坑、第一眼视觉反差 | 可 15 秒演示的物理反差结构（如单手拆洗/秒折收纳）、随附行业真材实料鉴别简卡 | 对比演示必须真实可复现 |
| **2. 已购买家（`Social Alibi` 社交借口层）** | 晒物不显炫耀或寒酸，获得得体人设 | 预留**高颜值实物拍照锚点**（极简器型轮廓、金属铭牌、带真实参数与工艺说明的品牌卡），给买家「懂行、反智商税、生活秩序感」的体面晒单理由 | 禁止在 Amazon 包裹塞返现或优惠券换晒单/留评 |
| **3. 核心粉丝（共创复购层）** | 圈层身份认同与优先参与感 | 独立站批次编号铭牌（如 `#0042` 需真实批次对应）、Reddit/Discord 社群配色或下一代改进投票权 | 不虚构虚假“限量”编号 |

## 模块 5：出海产品命名与全平台品牌锁权

### 5.1 命名五步工作流（先量后筛，严禁直接凑 3 个名字）

1. **生成 30–50 个内部候选**：覆盖 6 大方向（成分/材质、功能意象、使用场景、人群身份、地域符号、独立造词），每方向 ≥5 个；英文品牌/系列名优先控制在 **2–3 音节**、拼写直观无歧义。
2. **反面清单直接淘汰**：与同品类热销大卖读音/拼写近似（商标冲突风险）、母语者看着不会念、依赖谐音梗难以延展、把功效词写死（触发 FTC/FDA 审查）。
3. **100 分制评分过滤（`< 70` 淘汰）**：好念好记 `/25` + 意象贴合 `/25` + 系列延展性 `/20` + **多市场语言文化无雷区 `/20`** + **商标与域名可注册初判 `/10`**。
4. **回炉铁律**：达到 `≥ 70` 分的候选 **少于 3 个** → 返回第 1 步重新生成；「无雷区」或「可注册性」任一为 0 分直接淘汰。「可注册性」无专业检索工具时强制标注 `（初判，须经 USPTO/EUIPO/WIPO 检索确认）`。
5. **只交付 Top 3–5 候选并附完整打分表**。

### 5.2 命名锁权与首次商用证据链清单

- [ ] **商标与域名核查**：检索 USPTO TESS / EUIPO / UKIPO / J-PlatPat / WIPO Global Brand Database 及 `.com` 域名可用性
- [ ] **多语种禁忌筛查**：逐一核对英语（美/英俚语）、德/法/西语、日语读音及目标市场宗教文化避讳（配合 `mc-insight`）
- [ ] **全平台句柄（Handle）抢注锁死**：同步注册一致的 TikTok、Instagram、YouTube、X (Twitter)、Reddit 与 Pinterest 品牌官方 Handle，防止起量期被高仿号截流
- [ ] **首次商业使用（First Use in Commerce）证据链留档**：保留带时间戳的设计原稿、打样合同、独立站/Amazon 首批带商标实拍上架页及首笔真实交易订单与广告投放记录，支撑 USPTO §1(a) 声明与 Amazon Brand Registry 投诉举证

## 模块 6：产品线架构与「木马钩子 × 后手利润池」单元经济

> 非标高溢价三类补充角色（话题钩子款 / 同器型材质分档款 / 高玩高定锚点款）及退货率前置干预见 `references/physical-craft-premium.md` §4。
> 延伸新 SKU 的品牌署名架构见 `mc-brand` 模块 6 及 `brand-architecture-matrix.md`：单品/细分验证期同人群衍生默认用「主品牌 + 增强型描述词」（避免 USPTO 商标膨胀与 ABA 关键词分散）；若要向 Temu/低价清仓线铺货，**必须**采用「完全隔离式多品牌」以防 Amazon Buy Box 全网比价抓取直接剥夺主 ASIN 购物车。具备真实专利/实测差异的自研工艺，优先评估提炼**要素品牌（Ingredient Branding）**跨 SKU 复用。

### 跨 SKU 交叉补贴单元经济表（Hook SKU × Profit Pool）

单靠单一标品硬抗持续上涨的 Amazon PPC CPC 极易亏穿毛利。规划产品线时须算清**入口钩子品**与**后手利润池**的交叉补贴账：

| 角色维度 | 入口钩子品（木马钩子 SKU） | 后手利润池（利润回收 SKU / S&S） | 交叉补贴校验护栏 |
|---------|--------------------------|--------------------------------|----------------|
| **产品形态** | 高刚需、决策阻力低的入门单品或主机（Parent-Child 基础变体 / 入门装） | 专用替换耗材（开启 Amazon Subscribe & Save）、进阶配件、多件装礼盒、Virtual Bundle | 钩子与利润品须具强物理兼容或使用周期绑定 |
| **定价与毛利** | 允许贴近微利甚至设定明确**单客首单获客让利上限（`${X}/单`）**换取 BSR 与 Review | 维持高净利率（目标 ≥ `{Y}%`），承担跨周期利润回收 | 禁止没有后手复购/配件承接的长期亏本冲量 |
| **核心核算指标** | 首单 CVR、首单广告 CPA、退货率 | **二购率 / S&S 续订率（≥ `{Z}%`）**、连带购买率、**`N` 天回本红线（≤ `{N}` 天）** | `首单让利 + 首单广告费 ≤ N 天内后手利润池期望贡献毛利（续订/连带率 × 后手净毛利）` |

**核算纪律与断链警示**：用户未提供真实复购率或 S&S 续订数据时，所有预测数值**必须**标注 `[假设]`，并显式输出**断链亏损警示**——若实际连带/续订率低于临界值 `{Z_min}%` 或超出回本周期 `{N}` 天，前端放量越大现金流亏损越快，必须先用小批量验证连带转化率后再放开广告预算。

## 模块 7：上市前交接检查清单

- [ ] **成本过线**：已交 `mc-cost` 核算 Landed Cost、FBA Size Tier、关税与全成本净利率（≥ 25–28%）
- [ ] **合规过线**：已交 `mc-compliance` 核查目标市场强制认证、包装标签（原产国/窒息警告/EU 负责人）与插卡边界
- [ ] **商标与句柄**：商标初筛通过 + 社媒 Handle 锁死 + 首次商用证据留档
- [ ] **Listing 与上市**：输出交 `mc-listing`（转化立规与前置预期管理）→ `mc-launch`（90 天冷启动）→ `mc-ads`（L1 精准启动）
