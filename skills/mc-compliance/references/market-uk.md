# 市场规则 — 英国 (UK)

> last_verified: 2026-09-25 · 复核周期 180 天
> 由 mc-compliance 按需加载：目标市场含英国时读取本文件。审查参考，不构成法律意见；上线前由英国执业律师复核。

## 产品准入要点

| 要点 | 说明 |
|------|------|
| UKCA / CE 标识 | 英国政府已对大多数受监管产品无限期延续接受 CE 标识；特殊品类（医疗器械、建筑产品等）仍以最新过渡期公告为准 |
| UK Responsible Person | 特定受监管产品须在英国境内指定一名 Responsible Person 留存技术合规文档（不能用 EU 地址替代） |
| UK REACH | 独立于 EU REACH，化学品/高关注物质须单独履行 UK REACH 义务 |
| WEEE 与包装 EPR | 在 UK Environment Agency 单独注册 WEEE 及履行包装生产者延伸责任 |
| 英国 VAT | £0 注册门槛：非英国卖家在英国存储库存（含 FBA UK）须注册 UK VAT；≤£135 直邮订单由平台或境外卖家在销售时按 20% 代收代缴 |

## 文案、评价与营销合规（ASA/CAP · CMA · DMCC Act 2024）

| 检查项 | 风险 | 说明 | 依据 |
|--------|------|------|------|
| **广告可识别（网红披露）** | 高 | 营销传播必须显而易见是广告；网红内容至少应在开头显著标 `"Ad"`；`"gifted"` `"PR trip"` `"affiliate"` 等标签不足以说明商业性质；平台 Paid partnership 标签单独使用可能不够；每条内容均须单独标注 | CAP Code 2.1、2.3 [1]；ASA/CMA 网红指南 [2] |
| **误导与证据** | 高 | 不得误导；可客观核实的功效/对比声明在发布前必须持有充足证据 | CAP Code Section 03 (3.1, 3.7) [3] |
| **虚假评价严打** | 高 | 撰写、委托虚假评价，发布隐瞒激励的评价，压制差评或只挑好评展示均属一律禁止行为；展示评价的商家须采取合理措施预防并清除虚假评价 | DMCC Act 2024 附表 20 第 13 段 [4]；CMA208 指南 [5] |
| **滴漏定价 (Drip Pricing)** | 高 | 首次展示的价格必须包含所有可预见的强制性费用（服务费、强制手续费等），不得结账前才加价 | DMCC Act 2024 [4] |
| **CMA 直接执法罚款** | 信息 | 2025-04-06 起，CMA 可不经法院直接认定违反消费者保护法，最高罚款**全球年营业额 10%** | DMCC Act 2024 [4] |
| **不太健康食品 (LHF / HFSS)** | 高 | 2026-01-05 起：付费在线广告全面禁止；电视与受 Ofcom 监管点播服务 05:30–21:00 禁播（适用 13 类可识别 HFSS 食品/饮料） | ASA/CAP LHF 新规与指南 [6] |
| **酒类限制** | 高 | 出镜饮酒或担任主要角色者不得未满或看起来未满 25 岁；受众中未满 18 岁者超 25% 的媒体禁投 | CAP Code 18.15、18.16 [7] |

**待核实（未写入上表，不作审查结论）**：面向消费者的零售标价含 VAT 明示细节及 GB 营养健康声明注册表（GB NHC）具体允许措辞。
