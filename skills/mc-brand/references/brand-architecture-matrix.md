# 品牌架构扩展参考：购买三层级 · 双向溢出与比价隔离决策树 · 11 种次级关系 · 多主体传播秩序

> 由 `mc-brand` 按需加载：仅在涉及**多产品线扩张、孵化副牌 / Temu 低价跑量线、中国供应链/OEM 工厂转出海 DTC 品牌、自研材料/工艺独立命名（要素品牌）、或跨界联名/渠道专供款**时读取；单一 SKU 冷启动跳过。
> 全程守住真实：要素品牌与联名背书须具备真实专利、实验室检测报告或书面授权，禁止虚构海外 R&D 实验室、伪造集团背景或盗用未授权 IP。

## 使用顺序

1. 先用 §1 判定新 SKU 究竟该「沿用 Brand Registry 主品牌 + 增强型描述词」还是「新建子品牌/独立品牌」。
2. 确需区隔品牌层级时，逐关过 §2「双向溢出与 Amazon Buy Box 比价隔离」五关决策树，锁定主模式。
3. 在 §3「11 种次级关系谱系」中选定包装、Storefront 与 A+ 视觉署名颗粒度。
4. 若企业同时面对 B2B 采购/批发商、垂类测评机构与 C 端买家，按 §4 隔离发言主体与内容禁区。

## §1 消费者购买主界面三层级（防 USPTO 商标膨胀与 ABA 搜索分散）

不要把"每一个新 SKU"都注册成"一个新品牌"。海外买家心智与平台搜索权重天然分为三层：

| 层级 | 核心职能 | 命名与视觉形态 | 商标与搜索权重影响 |
|-----|---------|---------------|------------------|
| **1. 企业/制造背书层（Endorsement）** | 提供制造资质、安全兜底与机构信任 | 集团母标、合规责任主体或出品方署名 | 仅在 B2B/页脚/背面出现，不抢夺前台记忆 |
| **2. 购买主界面层（Purchase Entry）** | 买家真正记住、搜索与在 Amazon Brand Registry 注册的品牌主体 | 核心主品牌或独立子品牌（须注册 USPTO/EUIPO 文字商标） | **搜索词汇聚核心**，Brand Analytics 与复购心智沉淀于此 |
| **3. 增强型描述词层（Enhanced Descriptor）** | 标明规格、场景、材质版本或适配世代 | `{主品牌} + {场景/工艺/规格描述词}`（如 `Pro / Travel / Walnut Edition`） | **零新增商标注册费，直接承接 Amazon/Google 长尾搜索词** |

**反过度造牌铁律**：L1–L2 验证与细分期针对同一目标人群扩展新配色、容量、衍生配件时，**默认采用「主品牌 + 增强型描述词」**，严禁盲目造新子品牌名拆散自然品牌词搜索量与 Vine/A+ 品牌资产；仅当触发 §2 冲突或比价隔离条件时方启用子品牌或独立品牌。

## §2 母子品牌「双向溢出与 Amazon Buy Box 比价隔离」五关决策树

规划第二条产品线、Temu/低价清仓线、线下大卖场专供线或供应链转 DTC 时，自上而下逐关判定：

| 关卡 | 判定问题 | 分支走向与架构结论 |
|-----|---------|------------------|
| **第 1 关：控制权与合作周期** | 我方是否拥有该品牌资产的长期完整商标所有权？ | **否**（短期联名、IP 授权、代理经销）→ 走 §3 **跨界合作联名**，严禁并入母品牌主视觉与商标资产池 |
| **第 2 关：核心价值与人群冲突** | 新品定位承诺、审美调性与既有主品牌是否同向无冲突？ | **严重冲突**（如极简高端厨房 DTC 品牌切入一次性廉价派对用品）→ 直接进 **影子关联** 或 **完全隔离式多品牌** |
| **第 3 关：子反噬母检验（防 Amazon Buy Box 跨网抓价剥夺）** | 新品是否为**低价跑量线、Temu/清仓尾货或高退货率试水品**？挂同品牌会不会触发 Amazon 跨站点自动比价抓价剥夺主 ASIN **Buy Box（Featured Offer）**，或拉低店铺评分与人群锚点？ | **高反噬风险** → **强制「完全隔离式多品牌」**（独立店铺实体/Brand Registry、独立 UPC/EAN、独立主图与 A+ 版式、不共享主品牌词） |
| **第 4 关：母带子增益 vs 旧印记排异** | 母牌能否为新品增信？反向追问：**原有 B2B 工业厂名或平价大众印记是否劝退高溢价欧美 DTC 买家？** | · 强正增益无排异 → **单一品牌** 或 **母品牌驱动主副标**<br>· 需借工厂资质/安全合规托底但防工业廉价感 → **纯文字弱背书**（仅包装背面/合规标小字署名）<br>· 旧印记引发排异 → **影子关联** 或 **完全隔离式** |
| **第 5 关：多渠道价格与专供区隔** | 是否为 Walmart/Target/Costco 线下专供、特定独立站套装或地区渠道防止与 Amazon 主销款同款比价？ | **是** → 采用 **副品牌驱动式** 或 **独立型号编码 + 差异化包材规格** |

## §3 品牌关系 11 种精细表达谱系（5 大类 × 11 子式）

| 大类 | 次级模式 | 视觉与署名锁死规则 | 典型跨境适用场景 | 常见踩坑 |
|-----|---------|------------------|----------------|---------|
| **单一品牌** | **1. 同标一统式** | 全线共用同一 Brand Registry 商标与主视觉 | 心智高度聚焦的垂直品类专业品牌 | 跨到毫无关联的品类破坏专业信任 |
| **单一品牌** | **2. 同标分色/分缀式** | 主标字形锁死，按功效/材质线切换固定辅色或后缀 | 多功能户外配件、多系列厨房/收纳线 | 分色毫无规则，Storefront 变杂货铺 |
| **主副品牌** | **3. 母品牌驱动式** | 母标占包装与 A+ C 位，副系列名小字伴随 | 母牌已有高认知，顺势推 Pro/旗舰系列 | 母牌自身无搜索量时硬带，双双记不住 |
| **主副品牌** | **4. 副品牌驱动式** | 副品牌占正面主视觉，母品牌缩作角标背书 | 成熟跨境品牌切入年轻潮酷或细分垂类 | 角标过大喧宾夺主 |
| **背书品牌** | **5. 图形强背书式** | 子品牌标旁固定锁定「母标图形 + by [MotherBrand]」 | 跨品类安全延伸，需强借母牌安全信誉 | 子牌出 CPSC 召回或大面积 1★ 差评会连坐母牌 |
| **背书品牌** | **6. 纯文字弱背书式** | 正面 100% 独立品牌视觉，仅包装底部/合规页印出品主体 | **中国供应链/OEM 大厂孵化高审美出海 DTC** | 主图/品牌故事页大字堆砌工厂抬头，瞬间拉回白牌感 |
| **背书品牌** | **7. 象征印记背书式** | 不出现母品牌全称，仅共享家族词根、徽章轮廓或几何印记 | 多美学独立站矩阵，兼顾独立感与家族感 | 符号过隐晦，连老客也认不出关联 |
| **多品牌** | **8. 影子关联式** | 共享研发供应链与公司实体，但前台店名与社媒不主动互绑 | 平价走量线孵化高端专业独立站 | 用平价店直播/邮件直接导流或把高端款作赠品 |
| **多品牌** | **9. 完全隔离式** | 商标、Brand Registry、UPC、包装版式与客服域名 100% 隔离 | **Temu/低价防守副牌（防 Buy Box 抓价剥夺）**、高风险测试品 | 图省事共用同一套 A+ 排版或相同图片素材，被比价插件与卖家关联扒出 |
| **联合品牌** | **10. 要素品牌化（Ingredient Branding）** | 将自研结构工艺、专利涂层或专研配方独立命名并设技术徽标跨 SKU 复用 | **自研防摔/锁鲜结构、专利五金或专研配方跨线复用** | 拿公模常见普通原料强行造词冒充专利黑科技 |
| **联合品牌** | **11. 跨界合作联名（Co-branding）** | 双方商标并列锁定，限定周期与批次授权发售 | 海外 IP 联名、同客群互补出海品牌联合限量款 | 授权过期未清 FBA 库存触发商标投诉下架 |

> **要素品牌化立项与合规铁律**：必须对应至少 1 项可在 `mc-product` 模块 2「品类量化立规」中实测验证的物理/化学/专利差异；禁止虚构 `"German/Swiss Lab Joint Formula"` 等假海外科研机构背书（违反 FTC `Substantiation` 与 EU UCPD）。

## §4 多主体传播秩序隔离表（B2B 工厂背书 vs 技术线 vs C 端品牌）

| 发言主体 | 目标受众 | 核心沟通内容 | 承载触点 | 严禁串台禁区 |
|---------|---------|-------------|---------|-------------|
| **供应链/集团主体（制造背书）** | 线下商超买手、B2B 分销商、展商 | 产线规模、ISO/BSCI 认证、自动化良率与交付稳定性 | 阿里巴巴国际站、线下展会手册、LinkedIn 企业页 | **禁止**把"10万平米厂房/年产百万件"大字报直接塞进 Amazon 主副图或 TikTok 种草首屏 |
| **技术/要素品牌主体（专家角色）** | Reddit 参数党、YouTube 专业测评博主、发烧友 | 作用机理、公差测试条件、材质/结构迭代对比数据 | 技术白皮书、A+ 实测对比图、测评媒体 Brief | **禁止**脱离生活使用痛点堆砌无人能懂的学术黑话 |
| **C 端产品品牌主体（用户伙伴）** | Amazon/Shopify/TikTok C 端买家 | 具体生活场景痛点、感官体验、审美认同与社交谈资 | Listing 标题与 BP、A+ 故事、IG/TikTok 内容 | **禁止**用冰冷 B2B 说明书或官僚公文口吻和消费者说话 |
