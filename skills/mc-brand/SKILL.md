# Part I：品牌备案与知识产权保护（Module 1–4）

## Module 1：商标申请策略

### 1.1 目标市场 vs 注册局对照

| 销售市场 | 商标注册局 | 审核周期 | 参考费用（官方费） |
|---------|----------|---------|----------------|
| Amazon US | USPTO（美国专利商标局） | 8–12 个月（普通）/ 3–5 个月（IP Accelerator） | $250–$350/类 |
| Amazon UK / EU | EUIPO（欧盟知识产权局） | 4–6 个月 | €850 起（1类） |
| Amazon JP | JPO（日本特许厅） | 10–16 个月 | ¥12,000–¥28,000/类 |
| Amazon CA | CIPO（加拿大） | 18–24 个月 | CAD $458/类 |
| 中国工厂保护 | CNIPA（国家知识产权局） | 9–12 个月 | ¥300/类 |

> 建议优先注册 **US + EU** 覆盖主力市场，中国注册用于防工厂抢注。

### 1.2 商标类别选择（尼斯分类）

跨境电商最常用类别：

| 尼斯类别 | 覆盖内容 | 适用产品举例 |
|---------|---------|------------|
| **第 20 类** | 家具、家居装饰、收纳 | 收纳盒、椅子、架子 |
| **第 21 类** | 厨房用具、清洁工具 | 水杯、锅具、毛刷 |
| **第 25 类** | 服装、鞋、帽 | 服装类目 |
| **第 28 类** | 玩具、运动器材 | 健身器材、玩具 |
| **第 35 类** | 零售服务 | 建议同时注册保护销售行为 |

**原则**：注册你的产品所在类 + 第 35 类（零售服务），双重保护。

### 1.3 IP Accelerator 快速通道（Amazon 官方项目）

- Amazon 与认证律师事务所合作，申请期间即可使用 Brand Registry 功能
- 等待 USPTO 审核（通常 8–12 个月）期间不再是空档期
- 操作路径：`Brand Registry → IP Accelerator → 选择律所 → 律所代理申请`
- 适合：产品已在售、急需解锁品牌功能的卖家

## Module 2：Amazon Brand Registry 申请

### 2.1 申请条件

```
必须满足：
✅ 拥有活跃的商标注册号（或通过 IP Accelerator 申请中）
✅ 商标含文字（图形商标不够，需含品牌文字）
✅ 商标与品牌名在 Amazon 上一致
✅ 有效的 Seller Central 或 Vendor Central 账户
```

### 2.2 申请步骤

```
Step 1：进入 brandregistry.amazon.com
Step 2：点击 "Enroll a brand"
Step 3：填写信息：
  - 品牌名称（与商标完全一致）
  - 商标注册号
  - 注册局（USPTO / EUIPO / JPO 等）
  - 产品图片（含品牌 logo）
  - 产品类别
Step 4：Amazon 发送验证码至商标注册人邮箱
Step 5：输入验证码，提交审核
Step 6：审核通过（通常 3–10 个工作日）
```

### 2.3 注册后解锁的功能

| 功能 | 说明 | 价值 |
|------|------|------|
| **A+ Content** | 富媒体产品描述，提升转化 10–15% | 高 |
| **Premium A+ Content** | 视频模块、交互图，仅品牌卖家可用 | 高 |
| **Brand Analytics** | 搜索词报告、市场篮子分析、人群洞察 | 极高 |
| **Manage Your Experiments** | Listing A/B 测试 | 高 |
| **Vine 计划** | 邀请 Top Reviewer 写评论 | 中 |
| **Sponsored Brands 广告** | 品牌广告位（搜索结果顶部） | 高 |
| **Brand Stores** | 品牌旗舰店 | 中 |

## Module 3：防跟卖与侵权打击

### 3.1 跟卖类型识别

| 类型 | 特征 | 严重程度 |
|------|------|---------|
| **正常跟卖** | 卖真品，合法，但抢 Buy Box | 中 |
| **仿冒品** | 卖假货，用你的 ASIN，产品质量差 | 高 |
| **盗图跟卖** | 用你的主图但卖不同产品 | 高 |
| **品牌劫持** | 修改你的 Listing 内容 | 极高 |

### 3.2 反跟卖操作 SOP

**第一步：监控（每日）**

```
操作路径：Seller Central → Inventory → Manage All Inventory
→ 找到被跟卖的 ASIN → 查看 "Other Sellers on Amazon"
→ 记录：卖家 ID、价格、Seller Rating
```

**第二步：警告信（72小时内发送）**

```
警告信模板（英文）：

Subject: Cease and Desist – Unauthorized Sale of [Brand Name] Products

Dear Seller,

We are writing to notify you that you are selling counterfeit/unauthorized 
products using our registered trademark [BRAND NAME] (Registration No. XXXXXXX).

This listing (ASIN: BXXXXXXXXX) belongs exclusively to [Company Name]. 
Your unauthorized sale infringes our intellectual property rights under 
15 U.S.C. § 1125 and Amazon's Anti-Counterfeiting Policy.

We demand you immediately:
1. Remove all listings using our brand name or product images
2. Cease all sales of counterfeit/unauthorized [Brand Name] products

Failure to comply within 48 hours will result in a formal complaint 
to Amazon and legal action.

Sincerely,
[Your Name] | [Company Name] | [Contact]
```

**第三步：Amazon Report a Violation（品牌备案后可用）**

```
操作路径：
brandregistry.amazon.com → Protect → Report a Violation
→ 搜索 ASIN 或卖家 → 选择侵权类型：
  · Counterfeit（仿冒）
  · Trademark infringement（商标侵权）
  · Copyright infringement（版权侵权）
  · Patent infringement（专利侵权）
→ 上传证据（产品对比图、商标证书）
→ 提交
→ Amazon 通常 3–5 个工作日处理
```

### 3.3 Transparency 透明计划（防仿冒终极方案）

- 每件产品贴唯一防伪码（条形码），买家可扫码验真伪
- Amazon 在 FBA 入库时扫描，无码产品直接拦截
- 费用：$0.01–$0.05/件（按产品单价分级）
- 适合：已遭受严重仿冒、客单价 ≥$20 的品牌

**申请入口**：`brandregistry.amazon.com → Protect → Transparency`

## Module 5：资产光谱自下而上定位与双层人群锚定

### 5.1 五阶资产光谱自下而上提炼通道（专治白牌与工厂出海定位悬空）

中国供应链、ODM 工厂或硬件技术团队转型海外品牌时，**禁止硬编空洞的"改变世界 / 环保初心"伪使命**，改走「五阶资产光谱」自下而上反推，确保顶层主张自带可核实证据链：

```
第 1 阶：独占资产（We Own）     → 掌握什么稀缺工艺产线、专利结构、出厂质检标准或真实临床/实验室数据？
  ↓
第 2 阶：具体交付（We Deliver） → 基于这项资产，稳定交付哪一类量化高标产品（衔接 mc-product 量化立规）？
  ↓
第 3 阶：核心差异（We Apply）   → 里面用了什么同行 90 天内抄不走的结构公差、用料配比或耐久工艺？
  ↓
第 4 阶：角色身份（Who We Are） → 长期坚持这套做法，在海外买家眼里是什么角色（如"反过度溢价的工科死磕者"）？
  ↓
第 5 阶：使命主张（We Believe） → 最看不惯行业里什么劣质/虚标乱象、最捍卫买家的什么权利？（即真使命）
```

- **校验标准（含 Swap 替换测试）**：第 5 阶使命必须能倒推回第 1–3 阶物理/工程事实；同时把定位句里的品牌名换成最大竞品名字（Swap 测试）——如果依然成立，说明只是品类通用套话，必须重写。

### 5.2 「心智灯塔人群 × 商业扩展人群」双层锚定与「主驱动二选一铁律」

1. **双层人群防破圈稀释**：在 `brand-master.md` 拆开两层定义——
   - **心智灯塔人群（10%–20% 高势能核心客）**：对该品类最挑剔、活跃于 Reddit/YouTube 垂类社区的种子用户。**品牌的视觉审美、语调姿态与首发内容 100% 锚定他们，绝不为了迁就低价流量妥协调性。**
   - **商业扩展人群（80% 泛需求跟随客）**：信任专业测评或被场景打动的普通 Amazon/独立站买家。**通过 Amazon Search Terms、易懂的使用图解与入门规格向他们降低购买门槛。**
2. **功能驱动 vs 情感驱动「主次二选一」铁律**：Listing 首屏与独立站首屏 3 秒内**必须锁定唯一主驱动力**——要么以**功能硬收益**为主钩子（品牌故事做背书），要么以**审美/身份认同**为主钩子（参数作兜底）；禁止两者五五开平铺导致首屏失焦。

## Module 6：品牌架构与跨平台 Buy Box 比价隔离

当品牌不止一个产品线、拟推低价跑量款、或从 B2B 工厂切入 C 端时，按 `references/brand-architecture-matrix.md` 执行架构决策：

1. **防 USPTO 商标膨胀与 ABA 搜索分散**：决策界面分为「企业背书层 → 购买主界面层 → 增强型描述词层」。L1–L2 期同人群扩展新规格/口味/配件**默认采用「主品牌 + 增强型描述词」（如 `BrandX Travel Edition`）**，禁止盲目新建子品牌拆散搜索流量与 Brand Analytics 资产。
2. **母子双向溢出与 Amazon Buy Box 比价隔离铁律**：
   - **Temu / 低价清仓副线 / 高退货试水品** → **强制采用「完全隔离式多品牌」**（独立店铺主体、Brand Registry、UPC 与视觉版式），防止 Amazon 跨站抓价系统抓取同牌低价链接并剥夺主 ASIN Buy Box 购物车，同时防止差评连坐。
   - **OEM/ODM 工厂孵化高端出海 DTC** → **采用「纯文字弱背书式」**（正面 100% 独立新锐品牌视觉，仅包装背面/页脚小字标注制造出品方），避免工业厂名拉低海外感知价值。
   - **可检测的自研配方/专利结构** → 提炼**要素品牌化（Ingredient Branding）**跨 SKU 复用，把流量沉淀为技术护城河。
3. **合规底线**：要素品牌与跨界联名须具真实专利/实验室依据或书面授权；严禁虚构海外研发实验室或盗用未授权 IP。

## Module 7：品牌人格防线与对外发言人角色分层

### 7.1 主辅原型双轴相容性与「四象限人格过载黑化防线」

12 原型分布在「外向释放 ↔ 内敛克制」与「群体联结 ↔ 个体掌控」双轴上：主辅原型原则上选同象限或相邻象限，禁止未做触点隔离时混搭对角线反义原型。同时写入 `brand-master.md` 并在 `mc-grade` 双审中拦截四类过载黑化态：

| 人格象限 | 正常高光态 | ❌ 过载黑化态（触发即拦截重写） | 跨境纠偏护栏 |
|---------|-----------|--------------------------------|------------|
| **外向 × 掌控**（英雄/叛逆者/统治者） | 笃定敢言、挑战行业痛点 | **居高临下爹味说教、恶意拉踩指名竞品** | 锋芒对准行业坏规则，对买家始终平视尊重 |
| **外向 × 联结**（小丑/情人/探索者） | 鲜活有趣、有文化共鸣 | **硬蹭低俗/冒犯性网络烂梗、油腻推销** | 幽默仅用于自嘲或化解尴尬，涉及安全与退换立即严肃 |
| **内敛 × 掌控**（智者/魔法师/创造者） | 专业克制、逻辑与审美在线 | **冰冷 B2B 工程术语堆砌、端架子** | 每个专业指标必须翻译成买家日常体感变化 |
| **内敛 × 联结**（照顾者/普通人/天真者） | 真诚可靠、体贴克制 | **过度卑微客服腔（"Dear friend pls kindly..."）、毫无记忆点** | 温柔不等于无立场，在品质底线与合法原则上态度明确 |

### 7.2 对外发言人与引言角色分层纪律

新闻稿、海外播客、TikTok/YouTube 达人连麦及 Reddit 官方回应前，按角色 lock 发言权限：

| 角色 | 对外引言聚焦 | 严禁越界话题 |
|-----|------------|------------|
| **创始人 / CEO** | 行业演进判断、品牌为何而造、对用户的长期兜底承诺 | 具体工程公差参数、交期承诺、与竞品逐项口水对骂 |
| **具名产品 / 研发负责人** | 可溯源的测试条件、材料取舍、已知限制与改进时间线 | 公司战略定调、财务与融资金额 |
| **官方品牌账号 / Support** | 事实通报、处理进展时间表、退换/召回受理通道 | 个人主观情绪或未经确认的推测 |

> 禁止高管下场在社媒评论区与网友或竞品互撕；参数类声明必须具名到真实部门/测试依据，高管受访必须过 `mc-social`「30 秒防恶意切片」演练。

## Module 8：动态 VI 识别骨架（30/70）与全链路六大触点断层扫描

### 8.1 动态母体视觉架构：30% 不变量骨架 × 70% 可变量槽位

供 `mc-creative` 跨 SKU、Storefront、A+ 与 Meta/TikTok 矩阵直接落地：
- **30% 不变量识别骨架（全线锁死）**：标志性构图留白比例、核心几何容器/边框轮廓、主光影质地、品牌主色 HEX——**遮住 Logo 仍能 1 秒认出品牌**。
- **70% 可变量延展槽位（有序变化）**：分线辅色、目标市场本地生活道具、模特互动姿态、各平台画幅裁切比例。
- **6 选 1–2 系列化编码法**：色相分线法 / 容器取景窗法 / 母体骨架局部变异法 / 模块化徽章矩阵法 / 固定影调自由构图法 / 双章并列联名锁定期。

### 8.2 全链路六大触点调性断层扫描

1. **广告/社媒钩子**（是否用低质震惊体骗点击导致 Storefront 调性割裂）
2. **Listing 首图与标题**（是否坚守唯一主驱动与清洁视觉，而非牛皮癣贴纸堆砌）
