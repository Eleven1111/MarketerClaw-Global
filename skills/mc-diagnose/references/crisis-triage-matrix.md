# 海外口碑危机分流与过失×声量处置矩阵（`mc-diagnose` 按需加载）

> 加载时机：`pr_crisis` 模式触发，或卖家拿着一条 Reddit 吐槽帖 / TikTok 避雷视频 / Amazon 突发差评问"要不要发官方声明或律师函"时读取。
> 日常八维诊断不加载本文件。海外舆情数据由 `mc-monitor` 的 `Mode B：海外品牌口碑与舆情流速监控` 提供，本文件只负责分流定级与处置边界。

---

## 一、负面→危机三级前置分流门禁（外松内紧 · 防 Streisand 放大效应）

**为什么先分流**：海外社媒（Reddit / TikTok / X / Trustpilot）上的单条负面 ≠ 公共危机。对一条几百曝光的无据吐槽发官方声明或发律师函，等于替它买了一次全网曝光，极易把原本没人看的内容送上 Reddit 热门或 YouTube 吐槽合集（Streisand / 逆火效应）。

**外松内紧**：对外克制、不轻易公开硬刚；对内立即查批次与订单、备好口径、用 `mc-monitor` Mode B 暗中盯盘。

### Tier 1：低曝光噪音 / 明显无据吐槽

| 判定特征 | 处置动作 | ❌ 禁止动作 |
|---------|---------|-----------|
| 素人小号发布、零星互动、无事实或订单截图支撑、未跨平台传播 | 静默留档：截图 + URL + 时间戳归档，进观察名单 | 禁止官方账号下场回怼喂流量，禁止公开挂出个人账号 |
| 未出现第二个独立信源 | 每日例行复查一次，命中升格信号即转 Tier 3 | 禁止发空头 Cease & Desist 律师函威胁普通消费者（违反美国 CRFA `15 U.S.C. § 45b`） |

### Tier 2：低声量真实个案投诉（Amazon 订单 / Shopify 工单 / 局部社群）

| 判定特征 | 处置动作 | ❌ 禁止动作 |
|---------|---------|-----------|
| 有真实订单号、实物照片或具体物流/质量问题，但仍在小圈子传播 | ① 1v1 售后闭环止血：Amazon Buyer-Seller Messaging 或独立站 Zendesk/Gorgias 主动联系退款/补发，明确反馈时点 | **Amazon 严禁**：索要删差评、以退款换修改评分或带诱导的私聊 |
| 尚未命中 10 项升格信号 | ② 内部排查 FNSKU/生产批次并备好事实口径**引而不发** | 不得在事实未查清前发全网声明 |
| 讨论未破圈 | ③ 启动 `mc-monitor` Mode B 盯盘流速，同步将问题交供应链闭环 | 不得买水军洗地或投诉删帖 |

### Tier 3：危机升格信号（命中任一即进入危机响应）

| # | 跨境升格信号 | 典型观测口径 |
|---|------------|-------------|
| ① | 监管或消保机构点名 | CPSC / FDA / EU Safety Gate (RAPEX) / ACCC 召回或 FTC 警告 |
| ② | 垂直头部 YouTuber / TikToker 拆解曝光 | 粉丝远超品牌且评论区高度认同的独立测评发难 |
| ③ | Reddit / X / TikTok 单位时间互动流速激增 | 小时级转发/Upvotes 持续攀升且无衰减迹象 |
| ④ | 评论区一边倒谴责 | 帖子高赞热评几乎全是愤怒吐槽或跟帖补刀 |
| ⑤ | 同类安全/缺陷差评连续复现 | Amazon 近 7 天多个不同买家出现同一 1★ 缺陷描述 |
| ⑥ | 涉及人身安全、过敏、儿童、宠物健康底线 | 一旦涉及，不论当前曝光高低**直接升格** |
| ⑦ | Amazon NCX / Voice of the Customer 触发预警 | Listing 出现 "Frequently Returned Item" 标或安全投诉下架 |
| ⑧ | 内部敏感信息 / 客户 PII / 供应链文件外泄 | 后台利润截图、买家收件地址或内部邮件在外部流传 |
| ⑨ | Trustpilot / BBB 评分断崖或 Google 品牌词首屏沦陷 | 搜品牌名首屏出现大量避雷贴、Reddit 负评或维权汇总 |
| ⑩ | 命中 ≥ 2 类公众高敏情绪叠加 | 对照 `mc-monitor` Mode B 的 5 类高敏情绪叠加雷达 |

进入 Tier 3 后：先执行 `mc-diagnose/SKILL.md`「危机前线四道止血闸门」，再按下方矩阵落象限。

## 二、过失×声量 2×2 四象限博弈处置矩阵

**判定顺序（自上而下，命中即停）：**

1. **存在实质人身 / 健康 / 宠物 / 财产损害，且可归因于我方产品、说明书缺失或工艺缺陷** → **象限Ⅳ**（即使名义通过常规检测也归Ⅳ）。
2. **无实质安全/财产损害，合法合规但冒犯当地文化伦理、价格公平感或公众同理心** → **象限Ⅲ**；中途若出现个体受损，立即叠加象限Ⅳ的一线快速赔付授权池。
3. **事实无过失且无情感冒犯** → 按声量归入 **象限Ⅰ**（可控）或 **象限Ⅱ**（破圈）。

| 象限 | 过失判定 | 声量 | 核心策略 | 对接技能 |
|-----|---------|------|---------|---------|
| **Ⅰ** | 于理无过失 + 无情感争议 | 可控 | 冷处理定力：备好时间线与证据，仅在媒体/平台问询时点对点同步 | `mc-monitor` Mode B |
| **Ⅱ** | 于理无过失 + 无情感争议 | 破圈 | 同理关切 + 核实首发者 + 权威第三方拆解 + 定时心跳更新；禁止复述谣言细节，禁止威胁普通网友 | `mc-monitor` → `mc-compliance` |
| **Ⅲ** | 合法合规但冒犯同理心/文化 | 不论 | **先合情、再合理**：先承认感受真实，禁止甩法律免责条款或 "We apologize if anyone felt offended" 假道歉；给出实质改进与时间表 | `mc-brand` → `mc-compliance` |
| **Ⅳ** | 存在实质损害或我方确实有错 | 不论 | 魔鬼代言人阻断隐瞒 + **一线免 KPI 扣罚快速赔付池** + **锁界致歉**（锁定 FNSKU/批次与召回范围）+ 赔付落定后方可启用透明改进叙事 | `mc-diagnose` → `mc-compliance` → `mc-retain` |

### 四象限执行要点

- **象限Ⅱ防施压核实护栏**：核实首发者仅限了解损坏事实与批次，**严禁**以退款为条件要求删帖、改评分或签禁言协议（`16 CFR 465` / `CRFA`）。
- **象限Ⅲ家人自检**：把英文声明给不懂该产品的母语者/外部人读——如果对方觉得"他们在推卸讲理"而不是"他们听懂了我的生气"，重写。
- **象限Ⅳ一线免 KPI 扣罚快速赔付池**：授权客服/VA 在额度内对受损买家直接全额退款或补发且不扣绩效，黄金窗口内先把个案安抚到位，防止冲上 Reddit / 触发 CPSC。
- **象限Ⅳ锁界致歉**：精准写清问题批次号/FNSKU/生产日期及补救方案，禁止甩锅 "third-party supplier / shipping carrier / industry standard"，也禁止未核实就宣布"全线所有产品都有安全缺陷"制造无谓恐慌。
- **死局转换故事前置条件**：仅限致歉、召回与赔付彻底落定后，方可公开工厂质检升级过程或邀请真实用户监督重构信任；未赔先做公关秀必遭反噬。

## 三、全象限海外合规底线与输出格式

- **禁止**雇佣水军刷 5★ 好评压差评、禁止付费删评/删帖、禁止伪造第三方检测报告、禁止对普通评论者发空头 Cease & Desist 律师函。
- 所有对外公关声明发布前，**必须**通过 `mc-compliance`「危机声明反次生灾害 7 项否决检视」（核心声明 `≤ 400` 英文词）。

```markdown
### 负面分流与象限判定
- 原始负面：{URL / 平台 / 首发时间 / 涉及 ASIN-FNSKU}
- 分流结果：Tier {1/2/3}；命中升格信号：{编号或"无"}；高敏情绪叠加：{列表}
- 象限定位：象限 {Ⅰ/Ⅱ/Ⅲ/Ⅳ} — 依据：{事实与流速置信标注}

### 止血与处置动作（ICE 排序）
| 优先级 | 动作 | 负责人 | 时限 | ICE | 对接技能 |
|--------|------|--------|------|-----|---------|

### 下次复查与心跳通报时间：{UTC / 目标市场时间}
```
