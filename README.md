# MarketerClaw Global

AI 驱动的跨境电商营销智能体。24 个技能覆盖从选品造品、品牌架构、上线投放、B2B 买家开发、合规双审到舆情危机的全链路。

## 快速开始

### 安装（可选）

```bash
./install.sh               # 安装到 ~/.claude/skills/（Claude Code）
./install.sh --openclaw    # 安装到 ~/.openclaw/skills/（OpenClaw）
./install.sh --hermes      # 安装到 ~/.hermes/skills/（Hermes Agent）
./install.sh --local       # 安装到当前工作区 ./skills/
./install.sh /path/to/ws   # 安装到指定工作区
```

安装后在你的店铺工作区对话即可：品牌数据（`brand-brain/`）落在工作区内，不写入安装目录。

### 直接使用

也可以不安装，在 Claude Code 中打开本项目，直接说：

- "帮我优化这个 Amazon Listing"
- "销量下降了，帮我诊断一下"
- "给我做个月度经营数据看板"
- "新品上线，帮我做 Launch 计划"
- "转化率太低了，查查哪里漏了"
- "蓝牙耳机在 Amazon US 上谁卖得最好"
- "分析一下 Anker 和 Baseus 的竞争策略"
- "我要投 Amazon PPC，预算 $5000/月，怎么分配"
- "怎么做 TikTok 内容，找达人合作"
- "帮我设计 Amazon 主图和 A+ 图片"
- "复购率太低了，怎么提升 LTV"
- "帮我找一批美国/欧洲进口商和批发商，并起草合规英文开发信"
- "这个产品的 HS Code 是什么，关税多少"
- "3 个人的团队怎么安排日常运营"

## 系统特性

- **Brand Brain 数据总线**：所有技能共享品牌数据，消除信息孤岛
- **预设工作流**：7 套跨境场景自动串联技能（新品上线、增长突破、大促备战、B2B 海外拓客等）
- **危机模式**：现金流/Listing/库存/海外舆情（Tier 1/2/3 分流 + 过失×声量四象限）自动检测与响应
- **季节感知**：自动识别跨境电商季节阶段，调整策略倾向
- **三级降级**：数据不足时自动降级，保守输出，不编造数据
- **成本标签**：每条建议附带预算、见效时间、执行人
- **数据置信分级**：竞品与舆情数字标注实测/估算/推断，推断级数字不进精确对比和定价结论
- **反共识检验**：选品 GO 决策与文化洞察强制寻找最强反驳证据，防自证偏误
- **记忆回写**：复盘中验证/证伪的假设蒸馏进 Brand Brain，洞察跨周期复利
- **法域按需加载**：合规规则按市场与专项拆分（US/EU/UK/JP/AU/SEA/AI-Content），只加载涉及文件，省上下文
- **内容产出双环**：对外内容（Listing/创意/广告/社媒/B2B开发信文案）经 mc-compliance 硬门禁 + mc-grade
  软评分并行双审，首轮全量评审、第 2 轮起增量复核（只审改动 + 核验旧问题，防评审意见
  逐轮漂移不收敛），跑满轮次未过则暂停交用户裁决
- **技能内部模块化**：大篇幅与专项技能（mc-ads/mc-brand/mc-compliance/mc-cost/mc-diagnose/
  mc-logistics/mc-outreach/mc-product/mc-selection/mc-sop）拆为核心 + `references/` 按需加载模块，控制上下文占用
- **零依赖守卫测试**：`node --test "tests/*.test.mjs"` 自动校验 800 行上限、引用完整性、跨境合规红线与零外部归属
